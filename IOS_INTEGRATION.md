# iOS integration log

A separate team builds the iPhone app (`ios/`). This file is the running list of what changed on our side
(laptop, relay, contract, cloud) that the app has to pick up. **Anyone who changes what the phone receives, or
how it connects, adds a row here in the same commit.** At integration time, the iOS team works down the "Open"
list and moves each item to "Done".

- **The wire contract is `contracts/`.** The Swift mirror is `contracts/swift/HereContract.swift`, and it is compiled straight into the app.
- **Contract history:** `contracts/CHANGES.md`.
- **The phone can be tested without us:** `python -m relay` plus `python tools/fake_events.py --loop`, or a scripted scene: `python tools/fake_events.py --scene all --loop` (`fixtures/events/`).

## On-device acceptance (the three core moments)

Real array + laptop + phone + belt. Before each run: `.\tasks.ps1 demo-check` (= `python tools/check_gpu.py --demo`);
phone Settings → Relay = `ws://<laptop-ip>:8080/ws` + the token, You = the wearer's name, Belt connected and
tested, Calibrate facing the array's front; watch with `.\tasks.ps1 tap` (= `python tools/relay_tap.py --validate`).
Laptop for every row: `.\tasks.ps1 demo-up --source real` (= `python tools/demo.py up --source real`: local relay
on :8080 + `python -m laptop --real`, about 35 s to load models); `.\tasks.ps1 demo-reset` between tries. The array
runs fixed beams (`laptop/config.yaml`: `capture: beams`, `fixed_beams: [0.0, 180.0]`), so speech arrives at
world 0 or 180 only: stand talkers on those lines.
